Training Input Guide

Stratified cross-validation is shared across all methods. KNN also uses the neighbor count; the other methods keep their defaults fixed in this UI.

K-Nearest Neighbors

Inputs: dataset, validation folds, random state, and K neighbors.

Meaning: the model compares each case to the nearest training examples and predicts by vote.

Naive Bayes

Inputs: dataset, validation folds, and random state.

Meaning: the model scores each class probabilistically from the feature values.

Support Vector Machine

Inputs: dataset, validation folds, and random state.

Meaning: the model learns a separating boundary between the classes.
